  1. "Duration" — last night's hours vs the 7-9h target band: inside the band scores 100; outside, subtract 40 points per hour of distance from the nearest band edge, floor 0. Word/tone by subscore band: >=85 'optimal'/optimal, 70-84 'good'/good, 50-69 'fair'/fair, <50 'pay attention'/attention.
  2. "Consistency" — population standard deviation of the window's durations: subscore = (((2.0 - sd) / 1.5) * 100).clamp(0, 100). Same tone bands; the >=85 word is 'on rhythm' instead of 'optimal'.
  3. "Week trend" — split the window into an earlier half (first floor(n/2) nights) and later half (the rest); deltaMinutes = ((laterMean - earlierMean) * 60).round(). Subscore: 100 when deltaMinutes >= 0, else (100 + deltaMinutes).clamp(0, 100). Word/tone from deltaMinutes: >= +15 'trending up'/optimal, >= -15 'steady'/good, >= -45 'fair'/fair, else 'pay attention'/attention. When n < 4 nights, return the honest neutral: subscore 75, word 'steady', tone good.
  Overall `value` = (0.5*duration + 0.3*consistency + 0.2*trend).round().clamp(0, 100). Overall word/tone: >=85 'protective'/optimal, 70-84 'balanced'/good, 50-69 'fair'/fair, <50 'pay attention'/attention. `caption` = capitalized overall word + ' · ' + ('contributors steady' when zero contributors are fair/attention, 'one contributor to watch' when exactly one, '{n} contributors to watch' otherwise) — matching the copy-bank pattern 'Balanced · one contributor to watch'.
