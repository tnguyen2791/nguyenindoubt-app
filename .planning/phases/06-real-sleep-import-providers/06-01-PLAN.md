# Phase 6 Plan 06-01: Real Sleep Import Providers

## Goal

Make the existing patient sleep import flow use real platform providers where
available while preserving web/demo behavior and the sleep-only privacy model.

## Tasks

1. Add `health` dependency and conditional platform-provider boundary.
2. Extend `HealthDataProvider` with permission status and platform checks.
3. Implement HealthKit/Health Connect sleep-only read provider.
4. Add iOS and Android sleep provider configuration.
5. Change sleep summaries to aggregate provider sleep intervals by day.
6. Change local and Firebase imports to incremental dedupe/upsert behavior.
7. Surface permission state in the patient sleep import UI.
8. Add tests for provider states, sleep-only metrics, aggregation, and
   incremental sync.
9. Run `flutter analyze`, `flutter test`, Firestore rules tests, and a web
   build regression check.

## Verification

- `flutter analyze`
- `flutter test`
- `npm run test:firestore-rules`
- `flutter build web`
