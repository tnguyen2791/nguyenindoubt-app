# Phase 4 UI Spec

## UI posture

No large UI change is required for Phase 4.

## Required visible behavior

- The app must still run in local demo mode without Firebase configuration.
- If a Firebase/emulator mode selector is introduced, it must clearly state when data is account-backed versus local demo data.
- No Analytics, Crashlytics, telemetry, production monitoring, or hidden sync copy should appear.

## Deferred UI

- Invite validation, consent history, revocation, and clinician link lifecycle UI remain Phase 5.
