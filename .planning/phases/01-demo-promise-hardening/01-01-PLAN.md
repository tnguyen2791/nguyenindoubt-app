<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local browser/app storage to visible demo UI | The app displays sensitive demo-adjacent journal/import/consent state persisted on one device only. |
| Patient state to clinician state | Clinician mode may view accepted-link sleep summaries but must not receive journal data. |
| Safety UI to external crisis resources | Safety actions must route outward or provide fallback instructions without implying in-app emergency monitoring. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information Disclosure | Clinician dashboard/state | high | mitigate | Keep clinician data model to `PatientSleepBundle`; tests verify journal access throws `PrivacyException` and clinician UI does not render journal text. |
| T-01-02 | Repudiation / User expectation mismatch | Local demo persistence | medium | mitigate | Add explicit device-local copy and reset confirmation; reset restores seeded demo state and clears local persisted changes. |
| T-01-03 | Safety expectation mismatch | Safety page CTAs | high | mitigate | Replace no-op buttons with outward routing or fallback instructions and preserve no-monitoring/no-diagnosis copy. |
| T-01-04 | Denial of demo usability | Phone-width UI | medium | mitigate | Add responsive widget coverage and remove fixed-height/clipping issues in resource/safety/journal/clinician screens. |

</threat_model>
