# Phase 2 Plan: Auth and Session Model

## Steps

1. Add first-class session models and repository persistence.
2. Refactor app state to start signed out unless a saved local session exists.
3. Replace `_started` and the role toggle in `AppShell` with signed-out, onboarding, patient, clinician, and sign-out flows.
4. Update tests for onboarding, clinician demo override, session restore, and reset-to-signed-out behavior.
5. Run `flutter analyze`, `flutter test`, and `flutter build web`.

## Acceptance checks

- A fresh app instance shows signed-out entry options.
- Patient cannot enter the dashboard before completing onboarding.
- Clinician entry is explicitly labeled as a demo override.
- Recreating repository/state with the same preferences restores the expected patient or clinician session.
- Reset returns the app to signed out and clears local demo data.
