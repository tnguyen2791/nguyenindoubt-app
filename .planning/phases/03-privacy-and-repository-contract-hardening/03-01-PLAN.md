# Phase 3 Plan: Privacy and Repository Contract Hardening

## Steps

1. Refactor repository interfaces so clinician-facing contracts do not include journal reads.
2. Make patient journal reads requester-checked and update state to call the hardened methods.
3. Add link-status coverage for accepted, pending, revoked, and missing clinician sleep access.
4. Add clinician journal denial and no-journal-state tests.
5. Run `flutter analyze`, `flutter test`, `flutter build web`, and the GitHub Pages base-href build.

## Acceptance checks

- `ClinicianRepository` has no journal read method.
- Patients can still read and add their own journals.
- Clinicians can read sleep summaries only for accepted links.
- Pending, revoked, and missing links deny sleep-summary access.
- Clinician sessions do not expose patient journal entries through app state or UI.
