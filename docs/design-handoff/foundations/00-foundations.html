Hero readout

One big number per metric with a small unit and a short qualitative caption ("protective", "short night") — not a wall of stats.

One accent per metric

Muted, low-saturation base. A single accent carries the metric; a second, warmer tone only marks an off-target state.

Color encodes state

Green = on target, ember = flagged. Color is meaning, never decoration. Same rule across rings, bars, and lines.

Rings & rounded bars

0–100 summaries as soft gauges/rings; trends as rounded bars with the value labeled above and minimal gridlines.

Generous whitespace

Roomy padding, large radii, soft edges. Nothing crowded, nothing boxed-in. Let the number breathe.

Gentle motion

Values ease in; nothing pops abruptly. Transitions feel restful, matching a sleep/recovery context.
