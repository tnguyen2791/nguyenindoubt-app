Filled canopy action button; use one primary per view, ghost for the secondary path.

```jsx
<Button variant="primary" size="lg" fullWidth>Allow & continue</Button>
<Button variant="ghost">Continue with email</Button>
```

Variants: primary (canopy fill), ghost (canopy outline), quiet (mint fill), danger (ember text — sign out / destructive). size="lg" is the 15px full-width sheet CTA.
